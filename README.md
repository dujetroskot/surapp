Development of a Web Application for the Collection and Automated Analysis of Survey
Data Using Natural Language Processing and Machine Learning


The aim of this undergraduate thesis is to develop a web application for the automated
processing and analysis of survey data using statistical methods, natural language processing,
and machine learning. The developed application enables the upload of survey responses and the
corresponding configuration file, automatic data encoding, and the presentation of analysis
results. The developed functionalities were applied to data collected from 223 respondents. The
survey includes AAPS statements, textual explanations, and conceptual tasks in the field of
mechanics. Statistical analysis was used to examine the agreement between students’ responses
and expert responses, which averaged 45.93%, as well as the relationship between AAPS results
and conceptual performance. Machine learning models are used to investigate the possibility of
predicting results on conceptual tasks, while natural language processing is used to analyze
textual explanations and their relationship with Likert-scale responses and conceptual
performance. Django, HTML, CSS, Bootstrap, and Chart.js were used in the development of the
application.
